s2.validator.js — browser demo

Submit each form empty first, then with valid values. Rules come from rules.json, generated by the server validators (./gradlew :s2-validator:writeBrowserDemoRules).

1. Basic (native bubbles, number, trim)

2. Hidden fields (hidden input, closed tab, hidden radio group)

3. Checkboxes (consent, group)

4. Dynamic rows (wildcard rules, reindex after delete)
